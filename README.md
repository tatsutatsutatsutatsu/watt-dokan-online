# ワットでドカン！ -CARD BATTLE ONLINE-

電気工事・電力設備をモチーフにした、1vs1のオンラインカードバトルゲーム。
ワット数がそのままコストになる、シャドウバース風のルールで対戦する。

公開URL: https://watt-dokan-online.onrender.com

## 概要

- リーダー体力20、毎ターン最大電力+100W（上限1000W）、カードのコスト＝ワット数
- 盤面は最大4体。守護／疾走／突進／進化／ラストワード／ドレイン／必殺などのキーワードあり
- マリガン・ファティーグ・ターンタイマー（90秒）を実装したフル機能の対戦ルール

## 構成

- **server.js** — Node.js + `ws`。サーバー権威型でゲームロジック全体
  （カードプール・ターン進行・攻撃判定・マリガン・ファティーグ・
  ターンタイマー・CPU思考・戦績）を管理する
- **public/index.html** — クライアント本体。ビルド不要の1ファイル構成
  （ロビー・対戦画面・デッキビルダー・ランキング等すべて含む）
- **public/icons/** — 全カード共通デザインのドット絵アイコン
- **public/bgm_*.wav** — 自作BGM（バトル／ピンチ／ホームの3曲）

## 起動方法

```bash
npm install
node server.js   # または npm start
```

`http://localhost:3001` にアクセス。ポートは `PORT` 環境変数で変更可能
（Render等のPaaSにそのままデプロイできる）。

## 実装済み機能

- **対戦**：ルームコードによるオンライン対戦、ソロ（CPU）モード、
  再接続（切断から2分以内に復帰）、再戦、途中リタイア
- **CPU難易度**：よわい／ふつう／つよい（つよいはリーサル計算・除去の質・
  トレード判断を強化）
- **デッキ構築**：20枚・同名2枚まで、3スロット保存、サーバー側で検証
  （不正デッキはデフォルトデッキに自動差し替え）、共有コードでのエクスポート/インポート
- **カード**：全30種＋トークン1種。キーワードは守護／疾走／突進／進化／
  ラストワード／ドレイン／必殺。種族タグ（type）を将来のシナジー実装に備えて付与済み
- **UI**：カード一覧・ルール説明のサイドパネル、カード詳細（長押し/右クリック）、
  攻撃モーション・ダメージポップ等の演出、エモート
- **サウンド**：自作BGM3曲の切り替え（通常/ピンチ/ホーム）＋
  Web Audio生成の効果音、起動時のサウンドON/OFF選択画面、音量調整
- **戦績・ランキング**：対人戦／CPU戦（つよいのみ集計）を分離して記録、
  月間シーズン制、TOP3称号、開発者専用称号（環境変数`DEV_PLAYER_ID`で判定）
- **チュートリアル**：台本進行の特別ソロルームによる操作ガイド
- **PWA対応**：ホーム画面に追加してアプリ風に起動可能

## 開発の進め方

実装はCodexが担当し、Claude（チャット）が仕様策定・プロンプト作成・
コードレビューを担当する体制で開発している（開発初期はClaude Codeを使用）。

## デプロイ

GitHubリポジトリ（`watt-dokan-online`）にpushすると、連携済みのRenderが
自動で再デプロイする。**Render無料プランはデプロイ・再起動のたびに
ディスク内容が消える**ため、`stats.json`等の永続データは再デプロイで
リセットされる点に注意（月間シーズン制と相性はよいが、長期保存が必要に
なった場合はPersistent Diskや外部DBへの移行を検討する）。
